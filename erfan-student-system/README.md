# Erfan Student System

افزونه پنل دانش‌آموز عرفان.

- ورود و ثبت‌نام
- ساخت خودکار برگه‌های ورود، ثبت‌نام و پنل
- پنل دانش‌آموز مطابق طرح فعلی
- بخش کلاس آنلاین BigBlueButton
- پشتیبانی از لینک Join امضاشده از سمت سرور با فیلتر `erfan_student_bbb_join_url`

Secret مربوط به BBB نباید در مرورگر قرار بگیرد.

Shortcodes: `[erfan_login]`, `[erfan_register]`, `[erfan_panel]`
